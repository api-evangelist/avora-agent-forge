# AVORA Agent Forge

AVORA Agent Forge provides evidence-first Solana token risk scans.

Remote MCP for ChatGPT, Claude, Grok, and other compatible AI clients:
https://avora-agent-forge.netlify.app/mcp

MCP tools:
- scan_solana_token
- scan_solana_token_public_sector
- list_avora_offers
- create_starter_snapshot_order
- create_pro_report_order
- create_portfolio_report_order
- verify_starter_snapshot_payment
- verify_pro_report_payment
- verify_portfolio_report_payment
- get_avora_service_info
- get_verified_revenue_status

Free preview:
GET /api/agent/scan?mint={solana_mint}

List machine-readable offers:
GET /api/agent/offers?campaign={campaign}

Create a 1 USDC Signed Risk Snapshot order:
GET /api/agent/payment-order?tier=starter&mint={solana_mint}&campaign={campaign}

Create a 9 USDC Pro Evidence Packet order:
GET /api/agent/payment-order?tier=pro&mint={solana_mint}&campaign={campaign}

Create a 49 USDC Portfolio Due Diligence order:
GET /api/agent/payment-order?tier=portfolio&mints={comma_separated_2_to_10_mints}&campaign={campaign}

Verify payment and retrieve the selected paid artifact:
POST /api/agent/pro-scan
Content-Type: application/json
Body: {"tier":"starter|pro","mint":"...","reference":"...","orderId":"..."}

The service is non-custodial and never requests private keys or seed phrases.
Commerce telemetry is aggregate-only and does not publish wallet, mint, IP, or user identifiers.
Reports are technical information, not investment, legal, or tax advice.
Public-sector metadata is a voluntary alignment profile, not government approval or certification.
