# AVORA Agent Forge

AVORA Agent Forge is an evidence-first Solana SPL token risk scanner and public AI interoperability service for humans, wallets, and autonomous agents. It exposes two REST APIs (OpenAPI 3.1), a hosted MCP server, and an A2A agent card with published skills. Access is unauthenticated; paid tiers are gated by non-custodial, user-signed Solana Pay (USDC) settlement verified on-chain rather than API keys.
